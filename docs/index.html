Google Chrome 拡張機能

Amazon領収書一括ダウンローダー

確定申告・月次経理・経費精算のために、Amazon.co.jpの注文履歴から領収書・適格請求書（インボイス）をPDFで一括保存＆自動リネームする業務効率化ツールです。

主な機能

領収書・適格請求書をPDF一括保存

指定したページ数・期間（開始日〜終了日）の注文を自動巡回し、A4サイズのPDFとして一括ダウンロードします。適格請求書（インボイス）の原本PDFがある注文は原本を優先取得します。

経理ソフト向け自動リネーム

「20261117_3980円_Amazon_注文番号.pdf」のように日付・金額・注文番号で自動整形。年別フォルダ分けや変数カスタマイズにも対応しています。

注文一覧CSV出力＆重複スキップ

ダウンロードした全件の注文日・金額・商品名をまとめたUTF-8（BOM付き）CSVを同時出力。取得済み注文のスキップ機能で毎月の作業も快適です。
